
## И. Два режима правки заявки (вместо трёх)
- [ ] Убрать «Редактировать» из панели и полного экрана; большая форма — только создание
- [ ] Панель = быстрая правка (поля кликом, статус/приоритет в шапке, файлы + drag&drop)
- [ ] Полный экран = позиции, счета, логистика, комментарий, история; в панели строка «Позиции: N · Открыть на полный экран»
- [ ] Шапка полного экрана в том же контейнере 1440px
- [ ] Итог позиций — в подвал таблицы, колонка «Сумма», подпись «Итого»

## К. Колонки таблицы заявок
- [ ] table-layout auto, nowrap, width:1% всем кроме «Заявка» (100% + ellipsis)
- [ ] Выравнивание: Заявка слева, Сумма справа, остальные по центру (th = td)
- [ ] min-width 72px, max-width 260px для Объект/Контрагент + тултип
- [ ] Ширины стабильны внутри страницы
- [ ] При открытой панели прятать: Кто ведёт, Приход, Контрагент
