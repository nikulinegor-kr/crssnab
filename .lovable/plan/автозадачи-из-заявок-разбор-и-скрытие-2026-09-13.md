# Автозадачи из заявок: разбор и скрытие

## Ответы на вопросы

**1. Откуда брались названия «Аварийная заявка: …»**
Их создавала не программа интерфейса, а автоматическое правило в базе данных:
функция `sync_request_to_planner()` вместе с помощником `planner_upsert_auto_task()`
(добавлены миграцией `20260627155150`). Правил было четыре:
- `emergency_request` — «Аварийная заявка: <описание>»
- `invoice_pending` — «Оплатить счёт №… — …»
- `arrival_receipt`
- `delivery_due`

В коде приложения, edge-функциях, планировщике задач по расписанию и в MCP-инструментах
такого создания нет — только это правило базы.

**2. Когда запускалось**
Триггером на таблице заявок при создании заявки и при любом её изменении (статус,
исполнитель, счёт, даты). Это не разовая миграция. Правило уже отключено 6 сентября
(миграция `20260906074115`: триггер и функции удалены), новые автозадачи больше не появляются.
Триггера `trg_sync_request_to_planner` на заявках сейчас нет — проверено.

**3. Сколько их в базе и как отличить**
Всего задач 607, из них автоматических 602, вручную созданных 5.
Отличаются надёжно, не по названию:
- `source = 'auto_rule'` и заполненный `source_rule`
- `hidden_auto = true` (проставлено той же миграцией)

Разбивка: `invoice_pending` 186, `arrival_receipt` 161, `emergency_request` 130, `delivery_due` 125.

**4. Поле для безопасной выборки**
Да: `source` (`auto_rule` / `manual`) плюс `hidden_auto`. `created_by` не подходит — у автозадач
там подставлен обычный пользователь, а у 79 задач оно пустое.

## Почему они всё ещё видны

Планировщик их уже прячет (`hidden_auto = false` в запросе задач), а вот три места — нет:
- блок «Задачи по заявке» в карточке заявки
- счётчик задач у названия в реестре заявок
- расчёт «заявки без задач» для колонки «Не распределено»

## Что сделаю

1. `src/components/request/LinkedPlannerTasks.tsx` — в выборку задач добавить условие
   `hidden_auto = false`, чтобы в блоке остались только задачи, поставленные вручную.
2. `src/components/requests/RequestsTable.tsx` — счётчик задач считать только по
   `hidden_auto = false`; у заявок без ручных задач значка не будет.
3. `src/hooks/useRequestsWithoutTasks.ts` — при поиске «заявок без задач» игнорировать
   автозадачи, иначе такие заявки не попадают в «Не распределено».

Данные не удаляю и не меняю: 602 автозадачи остаются в базе, просто нигде не показываются.
