# Перестройка реестра заявок

## Что изменится

- Заменить блок из 15 показателей одной компактной строкой **«Требует внимания»**: «Просрочено», «Зависло дольше 2 дней», «Ждёт оплаты». Использовать существующие фильтры `overdue`, `stale`, `unpaid`; повторный клик снимает выбранный фильтр.
- Под строкой поиска выводить все активные фильтры отдельными чипами с крестиком. Включённый по умолчанию фильтр **«Скрыть доставленные»** всегда показывать чипом и учитывать в индикаторе активных фильтров.
- Оставить по умолчанию семь содержательных колонок: **Заявка, Объект, Статус, Контрагент, Сумма, Приход, Кто ведёт**. Дату, оплату, отгрузку, ТК, ТТН, заявителя, комментарий и другие дополнительные поля оставить в меню «Колонки».
- Сохранять выбор колонок отдельно для текущего пользователя в браузере. Старое сохранённое состояние корректно объединить с новым набором по умолчанию.
- Убрать порядковый номер строки и отдельную колонку приоритета. Приоритет показывать полосой 2 px слева у строки: красной для «Аварийно», янтарной для «Приоритетно», без полосы для «Планово».
- Статус показывать цветной точкой 6 px и обычным текстом с сохранением быстрого изменения по клику. Только значение «Просрочено» оформить красным текстом на фоне `danger-soft`.
- Все отсутствующие значения в ячейках показывать как «—».
- Убрать зебру, вертикальные разделители и внешнюю рамку таблицы; оставить тонкие горизонтальные линии `line`. Заголовок сохранить липким.
- В подвале таблицы показывать общую сумму всех заявок текущей фильтрации, а не только текущей страницы, и переключатель плотности **Плотно / Обычно / Свободно** (32 / 40 / 52 px) с сохранением выбора.

## Где будут изменения

- Страница реестра: размещение строки внимания, фильтров и таблицы без внешней рамки.
- Панель фильтров: чипы и индивидуальное снятие каждого фильтра без изменения существующих условий фильтрации.
- Таблица и настройка колонок: новый набор по умолчанию, визуал статуса/приоритета, пустые значения, подвал и плотность.
- Локальные стили реестра: горизонтальные линии, липкая шапка и высота строк через существующий `data-density`.

## Не меняется

- Источники данных, запросы, фильтрующие условия, группировка по объектам/проектам, сортировка, массовые действия, быстрое редактирование и боковая панель заявки.
