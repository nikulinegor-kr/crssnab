
## Раздел «Аналитика» — план реализации

Новый управленческий раздел в левом меню, отдельный от Dashboard и от блока «Документы» (Отчёт агента / Акт / Чеки). Цель — инструмент для принятия решений руководителем.

### 1. Навигация

В `src/components/AppSidebar.tsx` (группа после Dashboard) добавить новый раздел **«Аналитика»** с подпунктами:
- Исполнители — `/analytics/executors`
- Заявки — `/analytics/requests`
- Финансы — `/analytics/finance`
- Объекты — `/analytics/objects`
- Логистика — `/analytics/logistics`
- AI Аналитик — `/analytics/ai`

Доступ — через существующий `access-management` (роль руководителя/админа). Документы (Отчёт агента/Акт/Чеки) остаются в своём текущем разделе и не дублируются.

### 2. Страницы

**Исполнители** (`AnalyticsExecutorsPage`)
- Таблица по `profiles` (executor_id из `requests`): новые / в работе / выполненные / просроченные, %% в срок, средние времена (обработка, счёт, оплата, отгрузка, доставка), кол-во аварийных / приоритетных / плановых, сумма закупок, рейтинг (composite-метрика).
- Клик по строке → детальная страница `/analytics/executors/:id`: KPI-карточки, текущие заявки, история, графики (recharts): эффективность по месяцам, скорость выполнения, суммы по месяцам.
- Любая цифра в таблице/деталях ведёт на `/requests?executor=…&status=…` с применёнными фильтрами.

**Заявки** (`AnalyticsRequestsPage`)
- KPI-плитки по всем статусам (новые, входящие, в работе, в пути, доставлены, просрочены, аварийные, приоритетные, плановые, отменённые).
- Среднее время выполнения.
- График динамики по месяцам (создано/закрыто/просрочено).

**Финансы** (`AnalyticsFinancePage`)
- Bar: расходы по месяцам.
- Bar/Pie: расходы по объектам и по контрагентам.
- Списки: неоплаченные счета, просроченные оплаты.
- KPI: средний чек, средняя стоимость заявки.
- Топ-10 поставщиков по сумме.

**Объекты** (`AnalyticsObjectsPage`)
- Таблица по `request_objects`: число заявок, сумма, аварийные, средний срок поставки, тренд по месяцам, самые дорогие заявки (drill-down).

**Логистика** (`AnalyticsLogisticsPage`)
- KPI: в пути, доставка сегодня, просрочка отгрузки, просрочка доставки, среднее время доставки.
- Таблица эффективности транспортных компаний (по `delivery_company` из requests).

**AI Аналитик** (`AnalyticsAiPage`)
- Кнопка «Сформировать отчёт» → edge function `analytics-ai`.
- Функция собирает агрегаты за период (org-scoped) и шлёт их в Lovable AI Gateway (`google/gemini-3-flash-preview`).
- Возвращает структурированные выводы и рекомендации (markdown), пример:
  - тренды эффективности сотрудников,
  - перегруженные/отстающие исполнители,
  - проблемные поставщики и объекты,
  - аномалии расходов,
  - прогноз нагрузки и расходов,
  - конкретные рекомендации по перераспределению, сокращению сроков, оптимизации закупок.
- Результаты сохраняются в новой таблице `ai_analytics_reports` (org_id, created_by, period, content, created_at), чтобы можно было пересматривать прошлые отчёты.

### 3. Данные

Все запросы — на клиенте через `supabase-js`, скоупом организации пользователя. Где это тяжело — добавить SQL-вью/функции:
- `analytics_executor_stats(org, from, to)` — агрегаты по исполнителю.
- `analytics_request_timings(org, from, to)` — средние времена между статусами.
- `analytics_finance_monthly(org, from, to)` — суммы по месяцам/объектам/контрагентам.

Применяем существующий `useOrganization`, `usePermissions`. Reuse `recharts`, shadcn `Card`, `Table`, `Tabs`, фильтр периода (месяц/квартал/год/произвольный).

### 4. Технические детали

- Routing — добавить маршруты в `src/App.tsx` (lazy-loaded).
- Папка `src/pages/analytics/` для страниц, `src/components/analytics/` для виджетов (KPI-карточка, периодный фильтр, графики).
- Edge function `supabase/functions/analytics-ai/index.ts` с CORS, валидацией Zod, использованием LOVABLE_API_KEY и `streamText`/`generateText`. Кэшируем итоговый markdown в БД.
- Миграция: таблица `ai_analytics_reports` + RLS (только участники организации могут читать; вставка — авторизованным; полный доступ service_role) + GRANT.
- Каждая метрика — компонент-ссылка `<MetricLink to="/requests?...">`, чтобы клик вёл в готовый отфильтрованный реестр.
- Соблюдаем глобальные правила: Manrope, `.font-numeric` для чисел, mobile-first, поиск с дебаунсом 300 мс, REQ- скрыт в таблицах.

### 5. Объём и этапы

1. Sidebar + маршруты + skeleton-страницы (быстрый каркас).
2. SQL-функции и хук `useAnalytics*`.
3. Страницы Исполнители (с деталями), Заявки, Финансы, Объекты, Логистика.
4. AI-страница + edge function + миграция.
5. Подключение в `access-management` и проверка ролей.
